- **L01**: The emulator's Android Keystore is software-backed, so the key protection of the stored tokens is not hardware-backed there.
- **L02**: Re-consent for new user data (Health Card's phone number) asks for the ID and OTP again: eSignet's identity system releases user data only after an authentication, and eSignet Go keeps no browser session; Health Card's explainer screen says so. Extra scopes that need no new user data (the permission health_card_share) are approved on eSignet's consent page with no login (rule R28). The consent page names a permission by the text configured in `consent_scope_descriptions` (health_card_share: "Share your health card with clinics"), and by the raw scope value when no text is configured.
- **L03**: The server's runtime store is in memory, so an eSignet restart ends every Hub session; the e2e suite uses this to test the ended session.
- **L04**: Revoking the device secret (rule R27, Hub "Sign out of all apps") ends its session record, but access tokens already issued to Health Card stay valid until they expire: eSignet keeps the token deny list off. Without network the record ends by its time to live; the deleted DPoP key already blocks every use.
- **L05**: Hosted CI is read through the GitHub REST API with the team's login; the repository is private until submission, so the run page needs access to the repository. Every job was also replayed on Linux containers here (row CI-LINUX).
- **L06**: Emulator tests run on one emulator image (AVD ps03_api34, Google APIs x86_64, API 34, Chrome 113), not on other Android versions or browsers. The browser login steps of the UI tests can time out on a busy machine; a rerun passes.
- **L07**: The upstream Postman folders need the Postman desktop app (they use WebCrypto and top-level await that newman 6.2.2 lacks); nobody on the team has run them there. The Native SSO folder runs under newman.
- **L08**: No TalkBack or accessibility scanner run exists; accessibility is covered by JVM screen tests of both apps at 200 % font (HubScreensTest, CardScreensTest) and by the design rules only.
- **L09**: Nothing was run on a physical phone or on Linux or macOS machines of the team; the Go tests run in a Linux container on a Windows 11 laptop, and the CI jobs were replayed in Linux containers there.
